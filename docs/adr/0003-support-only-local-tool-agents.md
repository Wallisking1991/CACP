# Support only Local Tool Agents

CACP will focus its active product and compatibility surface on Claude Code, Codex, GitHub Copilot, and Kimi Code as Local Tool Agents. HTTP-based LLM API Agents are excluded from the current mainline because they have a different tool, permission, session, and capability model; prior work is preserved only on an archival branch and may return only through a future superseding decision.
