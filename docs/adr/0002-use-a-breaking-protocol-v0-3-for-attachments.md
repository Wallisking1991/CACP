# Use a breaking Protocol v0.3 for attachments

CACP will introduce structured message content, Room Attachment references, and Local Tool Agent capability negotiation as a coordinated Protocol v0.3 upgrade. Server, Web, and Local Connector will move together, old Connectors will receive an actionable upgrade error, and CACP will not maintain dual-format attachment readers because Live Rooms do not survive server restarts; native Agent sessions remain independently resumable.
